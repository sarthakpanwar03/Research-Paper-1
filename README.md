# A Pragmatic Approach of Heart and Liver Disease Prediction using Machine Learning Classifiers

This repository contains files and analysis related to the study *"A Pragmatic Approach of Heart and Liver Disease Prediction using Machine Learning Classifiers"*, which explores the potential of machine learning in the healthcare domain for disease prediction.

## Abstract
Heart disease, also known as cardiovascular disease, can lead to heart attacks by altering blood flow. Liver disease contributes to a global annual death toll of about 2 million. Adopting Artificial Intelligence and Machine Learning has the potential to transform healthcare. This work compares different machine learning classifiers, including Random Forest, Logistic Regression, Support Vector Machines, Naive Bayes, Decision Trees, and K-Nearest Neighbors, using four datasets sourced from Kaggle. The highest accuracies achieved across the datasets were:
- **Heart Disease dataset**: 82.35%
- **Heart Disease 2020 dataset**: 74.59%
- **Framingham dataset**: 68.6%
- **Liver Disease dataset**: 83.33%

## Repository Content
- **Results 1.xlsx**: Contains processed results and data summaries from the analysis.
- **Jupyter Notebooks**: Implementation and analysis of various machine learning models.
